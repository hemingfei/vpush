# 移动端图标底栏设计

## 目标

将移动端底栏改为接近 X App 的纯图标导航，去除可见汉字，降低纵向占用和视觉噪音，同时保留 V Push 的 Duty Blue 选中态、现有入口权限和滚动显隐行为。

## 设计决定

采用已确认的 B 方案：X 式等分图标布局，未选中项使用中性灰，当前入口使用 Duty Blue token（浅色 `#1668e0`、深色 `#5a9bf5`）；不增加圆形或胶囊背景。

### 入口语义

- 动态：主页图标。
- 财经新闻：报纸图标。
- 广场：四宫格图标。
- 个人设置：用户图标。
- 更多：省略号图标。

顺序、路由和权限保持现状。财经新闻仍可按运行时能力隐藏；“更多”仍仅对管理员显示，因此底栏必须在 3–5 个入口下等宽分布。

### 尺寸与状态

- 图标视觉尺寸约 `27px`，每个入口触控区域至少 `48px`。
- 移除底栏内所有可见文字，不用提示点、下划线或额外选中背景。
- 未选中图标沿用主题中性前景色；选中图标使用 Duty Blue。
- 浅色和深色主题使用相同状态语义，并保持足够对比度。
- 底部安全区、固定定位、下滑隐藏和上滑出现逻辑不变。

### 无障碍

可见文字移除后，每个按钮仍保留中文 `aria-label` 和 `title`。键盘焦点样式保留，隐藏状态继续使用 `inert` 阻止焦点和误触。

## 实现边界

- 复用现有内联 SVG 体系，不新增图标依赖。
- 仅调整移动底栏配置、渲染 HTML、对应 CSS、设计约束和前端测试。
- 不改变路由、权限、财经新闻能力判断、桌面侧栏或业务数据。
- 不改变已经上线的滚动方向显隐阈值。

## 验收

- `320px` 至 `768px` 下，3–5 个入口均完整、等宽且无可见文字。
- 五类入口使用主页、报纸、四宫格、用户、省略号图标，当前入口为 Duty Blue。
- 中文可访问名称和悬停提示完整，按钮可点击、可键盘聚焦。
- 浅色、深色、管理员、普通用户、财经新闻隐藏场景均正确。
- 滚动显隐、底部安全区和桌面导航无回归。
- 前端交互、运行时截图与静态检查通过。
