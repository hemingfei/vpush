# Web 图标体系与底栏 D1 动效设计

## 背景

V Push 网页端已经使用集中式内联 SVG，但通用图标仍存在局部字符图标、尺寸和线宽不统一的问题。移动底栏还会在部分 WebKit 或 Android WebView 环境中显示大块半透明蓝色点击高亮，与产品的纯图标导航不协调。

本设计延续现有“Duty Console”视觉方向，参考 Morphicons 对状态反馈的处理方式，但不引入 Morphicons 或其他运行时图标依赖。

## 目标

- 建立一套适用于网页端通用导航和操作控件的统一线框图标规则。
- 将移动底栏改为已确认的 D1 交互：点击时短暂淡蓝闪动，结束后仅保留蓝色加粗线框图标。
- 消除移动浏览器原生的大矩形点击高亮。
- 保持现有路由、权限、布局尺寸、主题和业务行为不变。
- 完成浅色、深色、普通用户、管理员和减少动态效果场景的自动化与视觉验收。

## 非目标

- 不改造微信小程序或 Android 原生壳层。
- 不引入 Morphicons、Lucide 运行时包或新的前端构建链。
- 不把平台、渠道或品牌标识改造成通用线框图标。
- 不为所有按钮增加闪动、路径变形或复杂动效。
- 不改变页面信息架构、底栏入口顺序、路由和权限判断。

## 方案决定

采用内部统一图标体系：继续由 `app/static/core/icons.js` 提供通用 SVG，通过现有 ES module 导入和依赖注入方式供页面使用。Morphicons 仅作为微交互参考，不作为代码依赖。

### 图标分类

1. **通用图标**
   - 包括导航、返回、关闭、展开、刷新、搜索、复制、删除等产品操作。
   - 集中在 `app/static/core/icons.js` 中维护。
   - 统一使用 `24 x 24` 画布、`currentColor`、圆角端点和圆角连接。
   - 默认线宽为 `2`；移动底栏持久选中态通过 CSS 提升为 `2.4`。

2. **品牌与渠道图标**
   - 包括雪球、微博、X、知识星球、华尔街见闻、Telegram、飞书、企业微信、Bark 和 Web Push 等标识。
   - 保留品牌原始填充、比例和颜色逻辑，不强制改成线框风格。
   - 已集中在 `core/platforms.js` 的图标继续留在该模块；现有渠道图标可保持当前所有权，不为本次改造做无关模块迁移。

3. **数据可视化 SVG**
   - 净值曲线、行情 sparkline 等按数据动态生成的 SVG 不属于图标体系，本次不调整。

### 字符图标替换边界

按钮中承担图标语义的 `‹`、`›`、`⌄`、`×` 等字符替换为统一 SVG，并保留或补齐中文 `aria-label` 与 `title`。数值正负号、正文破折号、验证码和其他内容字符不做替换。

### 展示尺寸

- 紧凑型操作：`16px`。
- 普通按钮和导航：`18–20px`。
- 移动底栏：`27px`。
- 展示尺寸由 CSS 控制，SVG 保持固定 `viewBox`；状态变化不得改变外框尺寸、图标尺寸或布局位置。

## 移动底栏 D1 交互

### 瞬时按下反馈

- 点击或触摸底栏按钮时，以图标中心显示一个 `42px` 的圆形淡蓝反馈层。
- 反馈层使用 `color-mix(in srgb, var(--color-accent) 12%, transparent)`，不保留边框、胶囊或矩形背景。
- 动效总时长为 `220ms`：快速显现后自然淡出。
- 动效只改变反馈层的透明度和受限缩放，不缩放或移动图标，不阻塞路由切换。
- 点击已选中的入口仍播放反馈；快速连续点击时重新开始当前反馈，不叠加多个效果。

### 持久选中态

- 动效结束后按钮背景完全透明。
- 当前入口使用 `var(--color-accent-text)`。
- 当前入口的线框图标使用 `stroke-width: 2.4`；未选中图标保持 `stroke-width: 2` 和 `var(--color-text-muted)`。
- 填充式“更多”图标只改变颜色，不伪造线宽变化。
- 不增加选中圆点、下划线、位移或尺寸变化。

### 原生点击高亮

移动底栏按钮显式关闭 `-webkit-tap-highlight-color`，防止 Android WebView 和 WebKit 的默认矩形高亮与自定义圆形反馈重叠。该规则限定在底栏，不全局关闭浏览器反馈。

### 减少动态效果

在 `prefers-reduced-motion: reduce` 下取消扩散和空间变化，仅使用一次 `80ms` 的淡蓝透明度反馈，然后进入稳定选中态。路由反馈和当前入口识别必须继续可见。

## 交互与无障碍

- 底栏每项继续保持至少 `48px` 高，并在 3–5 个入口时等宽分布。
- 图标 SVG 使用 `aria-hidden="true"`，由按钮提供可访问名称。
- 每个纯图标按钮必须具有明确的中文 `aria-label`；桌面可悬停的图标按钮同时提供 `title`。
- 当前底栏入口设置 `aria-current="page"`，路由变化时移除旧入口的该属性。
- 键盘 `:focus-visible` 外框沿用现有全局规则，不能被点击反馈覆盖。
- 反馈层使用按钮伪元素，设置 `pointer-events: none`，不得遮挡图标或相邻按钮。
- 浅色和深色主题均复用现有语义色 token，不新增硬编码主题分支。

## 实现边界

实现只涉及以下区域：

- `app/static/core/icons.js`：补齐字符图标对应的通用 SVG，并统一直接相关图标的结构属性。
- `app/static/app.js` 及使用字符按钮的视图模块：使用统一 SVG，触发底栏反馈，并同步 `aria-current`。
- `app/static/style.css`：实现 D1 反馈层、选中线宽、原生 tap highlight 修复和减少动态效果分支。
- 前端静态契约和 Playwright 测试：固化图标及底栏状态行为。
- `DESIGN.md`：在实现阶段同步长期图标和动效约束。

不借此改造重排现有大文件、迁移品牌图标所有权或清理无关样式。

## 验收标准

### 自动化检查

- 当前入口具有 `active` 和 `aria-current="page"`，旧入口在路由切换后同时失去两者。
- 底栏稳定选中态的背景为透明，通用线框图标为蓝色 `2.4` 线宽。
- 未选中通用图标为中性灰 `2` 线宽。
- 底栏关闭原生 WebKit tap highlight。
- 点击任意入口和重复点击当前入口都能重新触发一次反馈，且不会累积反馈节点。
- `prefers-reduced-motion` 分支不执行扩散动画。
- 底栏按钮的可访问名称、标题、焦点和最小触控尺寸保持正确。

### 浏览器视觉验收

- 手机窄屏和 `768px` 边界下，3、4、5 个入口均无重叠或布局位移。
- 浅色和深色主题中，闪动为圆形、轻量且在 `220ms` 后完全消失。
- 动画结束截图中没有持久矩形、圆形或胶囊背景，只保留蓝色加粗线框图标。
- 管理员“更多”入口、财经新闻动态显示和底栏滚动显隐行为无回归。
- 桌面侧栏和非底栏按钮没有获得 D1 闪动。
- 全站按钮中的目标字符图标已替换，品牌图标与数据图表未被误改。

## 成功定义

用户在移动网页或 Android WebView 中点击底栏时，只看到一次克制的圆形淡蓝反馈；反馈结束后，当前入口由蓝色加粗线框稳定表达。全站通用图标在画布、线条、尺寸和无障碍语义上保持一致，同时不增加新的运行时依赖或改变业务功能。
