# IMA 知识库设置主从工作台设计

日期：2026-08-31
状态：已确认

## 目标

把「采集」页的日常主流程从“展开目录树”调整为：

1. 选择知识库。
2. 调整同步频率。
3. 管理查看权限。

采集目录范围很少变化，因此降为按需展开的低频配置。设计不改现有后端接口和保存语义。

## 设计原则

- 遵循 V Push Duty Console 设计：灰底白面、1px 描边、平面层级。
- Duty Blue 只用于选中、主操作和焦点，面积保持克制。
- 不在页面卡片内继续堆卡片；主从区域是一个连续的管理工具。
- 桌面保持高密度扫描，手机保持 42-44px 触控目标。
- 权限修改即时生效；同步频率和采集目录显式保存。

## 桌面布局

### 页面头部

保留「采集 / 星球 / 存储 / 本地库」一级标签和「IMA 文档采集」标题。

工具头显示：

- 已发现和最近同步的知识库数量。
- 「重新发现」次要按钮。

### 左侧知识库列表

固定宽约 280px，只承担知识库选择：

- 名称。
- 来源状态（旧配置 / 自动发现）。
- 已选目录数量。
- 当前库使用浅蓝选中态，尺寸不变化。

同步频率不再重复出现在每一行，避免四组分段控件抢占注意力。

### 右侧知识库详情

选中知识库后依次显示：

1. **运行栏**：知识库名称、健康状态、「同步当前库」按钮。
2. **同步频率**：1h / 6h / 24h 分段控件，并显示下次计划同步时间。
3. **查看权限**：人数、即时生效说明、常驻搜索添加框、紧凑成员标签。
4. **采集文件夹**：默认收起，仅显示已选数量和父目录继承说明；点击后在原位展开目录树。

成员标签默认限制为约两行，并提供「展开全部 N 人」。移除操作继续使用标签内的关闭按钮。

### 保存区

频率或目录发生修改后，工具底部显示未保存状态：

- 左侧说明有未保存修改。
- 右侧提供「放弃修改」和 Duty Blue 主按钮「保存采集配置」。

没有未保存修改时不制造强提示。权限操作不进入此保存队列。

## 手机布局

在小于等于 900px 时切换为单栏：

- 左侧知识库列表改为全宽知识库选择器。
- 运行状态、同步频率、权限和文件夹按桌面相同顺序纵向排列。
- 频率分段控件三等分，单项高度至少 40px。
- 「重新发现」和「同步当前库」使用带 `aria-label` 的刷新图标按钮。
- 有未保存修改时底部显示粘性保存条，只保留主要保存命令。
- 权限标签默认显示较少项，通过「展开全部」查看完整列表。

## 状态与错误

- 切换知识库时保留当前已有的草稿保护逻辑，未保存修改不可静默丢失。
- 权限添加或移除失败时在权限区域内提示并保留原状态。
- 目录加载失败时在展开区域显示错误和重试，不影响频率及权限操作。
- 重新发现失败时保留当前知识库列表，不清空可操作内容。
- 同步触发后沿用现有进度和状态反馈。

## 可访问性

- 知识库列表继续使用 `listbox` / `option` 语义。
- 文件夹树继续使用 `tree` 语义和键盘展开行为。
- 分段频率控件提供明确选中状态。
- 图标按钮提供中文 `aria-label`。
- 输入焦点使用 Duty Blue 描边和浅蓝焦点环。
- 所有主要触控目标高度保持 42-44px。

## 实现边界

复用现有 IMA 状态、接口和保存方法，仅调整 `app/static/app.js` 的结构和 `app/static/style.css` 的布局样式。

本次不做：

- 新增后端接口或数据字段。
- 权限批量模板。
- 多知识库批量编辑。
- 自动保存同步频率。
- 改变目录父子继承规则。

## 验收标准

- 桌面首屏无需滚动即可选库、改频率、搜索添加权限用户。
- 权限成员较多时不会把采集文件夹和保存区推到不可预期的位置。
- 目录树默认不占据主内容高度，展开后仍可独立滚动。
- 手机宽度下无水平滚动、文字重叠或小于触控要求的命令。
- 权限仍即时生效，频率和目录仍需要显式保存。
- 原有错误、草稿保护、同步进度和键盘语义不回归。
