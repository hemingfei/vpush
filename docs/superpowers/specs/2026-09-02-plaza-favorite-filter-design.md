# 订阅广场“特别关注”筛选收纳设计

## 目标

解决订阅广场顶部“特别关注”胶囊在窄宽度下换行、视觉上像独立主操作的问题，同时保留一键筛选能力和当前数据语义。

## 设计决定

采用“收进筛选面板”方案。“特别关注”是低频范围筛选，不再长期占据顶部工具栏；卡片内用于设置或取消特别关注的星标按钮保持不变。

### 桌面

- 顶部工具栏保留搜索、平台筛选和“已订阅”快捷筛选。
- 原“特别关注”胶囊替换为现有漏斗筛选按钮。
- 筛选面板包含分类、“只看特别关注”开关和“清除筛选”。
- 面板默认收起；点击漏斗展开或收起。
- 分类或特别关注启用时，漏斗使用现有 Duty Blue 激活态。搜索和“已订阅”在顶部直接可见，不计入漏斗激活态。

### 手机

- 保持现有 7 格等宽平台/筛选角标，不增加文字胶囊。
- 搜索、分类、“已订阅”和“只看特别关注”继续放在筛选面板内。
- 任一面板内筛选启用时，漏斗角标使用 Duty Blue 激活态。

## 交互与状态

- “只看特别关注”继续复用 `state.homeFavorite` 和现有本地目录过滤，不新增接口或请求。
- 开关变化后立即刷新列表；“清除筛选”继续复位搜索、分类、已订阅和特别关注。
- 不增加额外的结果状态标签，避免同一筛选被重复展示。
- 漏斗按钮保留 `aria-expanded`、`aria-controls`；范围开关保留 `aria-pressed` 和清晰的可访问名称。

## 实现边界

- 仅调整 `renderHome()` 的筛选布局、必要的共享 HTML helper 和对应 CSS。
- 不改订阅、特别关注、次要大V的接口与业务逻辑。
- 不改卡片操作区，不改动态页筛选，不新增组件、依赖或持久化状态。

## 验收

- 桌面任意支持宽度下不再出现换成两行的“特别关注”顶部胶囊。
- 桌面可从漏斗面板开启/关闭特别关注筛选，状态和清除操作正确。
- 手机维持 7 个等宽、至少 44px 的角标，筛选面板功能不退化。
- 浅色和深色主题均沿用现有 token，激活态清晰但不新增强调色。
- 前端交互测试、JavaScript 语法检查和桌面/手机截图检查通过。
