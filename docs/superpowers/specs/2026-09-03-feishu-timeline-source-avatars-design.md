# 飞书时间线来源头像

- 日期：2026-09-03
- 状态：设计已确认
- 范围：研报库飞书时间线的来源切换，以及同一套来源显示名

## 目标

让杨康平和失业期神两条飞书时间线能一眼分开。头像只出现在顶部切换，不出现在每条记录上。

## 已确认的选择

- 只复用动态广场的顶部胶囊，不复用动态卡片，不把飞书搬进 `/timeline`
- 按来源认人，不按发言人
- `K神-2026` 显示为杨康平，配眼镜卡通头像
- `Q神-档案库` 显示为失业期神，配蓝剪影头像
- 头像是仓库内静态文件，走和 `style.css?v=` 一样的本地缓存；不当 404 产品场景

## 设计

### 1. 顶部切换

飞书阅读器顶栏的来源 `<select>` 换成胶囊：

- 全部
- 杨康平（头像 + 名字）
- 失业期神（头像 + 名字）

点胶囊仍调用现有 `selectFeishuTimelineSource`，过滤逻辑、7 天窗口、游标分页不变。

多个来源时显示「全部」；只有一个来源时显示该来源胶囊，不必再出「全部」。没有对照表的来源保持原名、不配头像。

### 2. 显示名对照

后台 `group_id` 不动。前端用一张小表把已有来源名映射成显示名和头像：

| 现有来源名 | 显示名 | 头像 |
| --- | --- | --- |
| `K神-2026` | 杨康平 | 眼镜卡通 |
| `Q神-档案库` | 失业期神 | 蓝剪影 |

别名同样命中：`杨康平`、`Q神`、`失业期神`。

同一张表用于：

- 顶部胶囊
- 混看时条目上的灰色来源名
- 研报库列表/筛选里这两条飞书库的名字

### 3. 头像文件

用户提供的两张图压成小圆头像后放进 `app/static/`，例如：

- `app/static/feishu-yang.png`
- `app/static/feishu-shiye.png`

`<img src="/feishu-yang.png?v=1">` 这类带版本的本地地址。不走飞书接口，不走 `/avatars` KOL 代理，不加上传入口，不加数据库字段。

原图约 1–2MB，入库前裁圆所需的小图，不把原图原样塞进仓库。

### 4. 时间线条目

条目保持现在的快讯结构：时间 | 正文。不在每条上叠头像。表格、图片、附件、发言人/回复、日期目录、回到最新，全部不动。

### 5. 不做

- 按发言人匹配头像
- 动态卡片（头像 + 名字 + 相对时间）
- 把飞书源塞进 `/timeline` 平台胶囊
- 特别关注、次要大V、查看原文、右侧发现栏
- 头像 404 兜底产品逻辑；文件缺失是发版问题

## 测试

- 顶栏是胶囊不是下拉框；杨康平、失业期神有头像
- 点胶囊仍按原 `group_id` 过滤
- 混看来源名是新名字，不是 K神/Q神
- 研报库列表同样显示新名字
- 时间线条目 HTML 不含来源头像
- 静态头像 URL 带版本参数
