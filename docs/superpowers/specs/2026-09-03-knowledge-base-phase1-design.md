# 研报库 Phase 1 前端交互与美观性优化

- 日期：2026-09-03
- 状态：设计已确认
- 范围：研报库（`/knowledge`）列表页排版、顶部搜索与筛选区、手机端来源切换、阅读器摘要卡片展示

---

## 一、目标

解决研报库当前长标题截断严重、单行表格缺乏质感、移动端来源切换横向溢出及详情页摘要平淡的问题。在保持极速加载与轻量架构的前提下，将研报库提升为具备现代投研质感与高阅读效率的知识中心。

---

## 二、已确认的设计决策

1. **列表呈现形态**：采用**投研微卡片流（Card Flow）**。每篇研报为独立轻卡片，标题支持最多 2 行折行，直接透出 1~2 行核心摘要，附带机构微徽章与等宽元数据。
2. **顶部筛选布局**：采用**独立搜索条 + 次级过滤胶囊栏**。搜索框独占首行；次行排布分类来源与日期/标签筛选，避免搜索框被挤压。
3. **手机端来源切换**：自适应切换——**桌面端（≥768px）保留横向 Pills 胶囊；手机端（<768px）自动切换为原生下拉选择菜单（Select）**，避免小屏横滑与误触。
4. **详情页摘要高光**：阅读器顶部摘要采用**专业投研 Callout 卡片**（浅色背景 + 左侧 Accent 高光条），并配备一键「复制摘要」操作。
5. **数据字段扩充**：后端 `_public_list_item` 扩充输出截取前 140 字的 `abstract`，列表无需二次发请求即可显示摘要预览。

---

## 三、详细设计

### 1. 顶部搜索与筛选区解耦

- **首行独立搜索框**：
  - 占满容器宽度，左侧保留搜索图标，右侧增加实时的清空 `✕` 按钮（仅在有输入内容时显示）；
  - 移除原先强塞在搜索框内部右侧的 `.kb-desk-day` 日期按钮，还给用户完整输入区域。
- **次行过滤工具栏**：
  - **桌面端（≥768px）**：左侧为来源分类胶囊 Pills（`全部`、`各研报库`，选中态高亮），右侧排列「`📅 日期: 全部 ▾`」按钮与「`标签 ▾`」下拉选择；
  - **手机端（<768px）**：来源库收纳为一个紧凑的下拉菜单 `<select>`（文案形如 `📚 全部研报库`、`📚 中金研报`），与日期、标签紧凑平铺在一行或两行，占用高度固定且不溢出。
- **状态同步**：
  - 切换来源库时更新 URL `?group=...`，触发列表重刷；
  - 搜索框防抖（250ms）或按回车即时检索。

### 2. 研报列表微卡片流 (Card Flow)

- **DOM 结构**：
  - 由原先的行栅格 `.ima-doc-row` 升级为语义化的微卡片 `.ima-doc-card`（保留键盘可访问性 `tabindex="0"` 与 `role="button"`）。
- **视觉层级**：
  - **头部元数据（Header）**：
    - 左侧：资料源/机构浅色微徽章（Badge），如券商（淡蓝背景）、自建库（淡灰背景）；
    - 右侧：发布日期（`09-03` 等宽对齐）、页数（`42P`）、文件大小（`3.6M`）。
  - **标题（Title）**：
    - 字号 `var(--text-body)`，字重 `font-weight: 600`，行高 `1.42`；
    - 允许最多 2 行显示（`-webkit-line-clamp: 2; display: -webkit-box; -webkit-box-orient: vertical; overflow: hidden;`），长词断行 `overflow-wrap: break-word`。
  - **摘要透出（Summary / Snippet）**：
    - 优先展示带关键词命中的 `search_snippet`；未搜索时展示轻量 `abstract`；
    - 最多展示 2 行（`-webkit-line-clamp: 2`），字体颜色为弱化灰字 `var(--color-text-muted)`；
    - **优雅降级**：若文档既无 snippet 也无 abstract，该区域自然收缩折叠，卡片整体高度贴合标题，不产生空行。
- **交互与动效**：
  - 鼠标悬停（Hover）：背景轻微加深（`var(--color-surface-soft)`），边框过渡柔和；
  - 选中态：左侧 3px Accent 颜色条纹或微蓝背景，明确当前阅读上下文。

### 3. 阅读器详情页「高光观点卡片」

- **样式设计**：
  - 在 `.ima-reader-info` 内，将原生 details 升级为 `.ima-reader-callout`；
  - 容器背景采用微蓝底色（浅色模式：`var(--color-surface-soft)` 配合 1px 微边框与 4px 左侧高亮边 `border-left: 4px solid var(--color-accent)`）；
  - 头部展示 `💡 核心观点 / 研报摘要` 标题与一键 `📋 复制摘要` 按钮；
  - 正文排版：字号 13px，行高 1.65，默认展现最多 4 行，超长时显示「展开全部」平滑伸展。
- **复制功能**：
  - 点击 `📋 复制摘要`，优先调用 `navigator.clipboard.writeText`，回退调用 `document.execCommand('copy')`；
  - 复制成功后弹出既有全局气泡 `flash("已复制研报摘要")`。

### 4. 后端接口扩充 (Backend API)

- **修改文件**：`app/ima_documents.py`
- **修改函数**：`_public_list_item(item: dict[str, Any]) -> dict[str, Any]`
- **新增逻辑**：
  ```python
  abstract_text = str(item.get("abstract_zh") or item.get("abstract") or "").strip()
  if abstract_text:
      public["abstract"] = abstract_text[:140]
  ```
- **影响范围**：
  - 仅在返回列表公共数据时带上短文本摘要，不修改底层存储与扫描逻辑；
  - 不引入额外数据库索引或新依赖。

## 四、异常与边界处理

1. **极端字符与超长标题**：测试包含中英文混排、代码符号（如 `(600519.SH)`）、连字符的极端长标题，确保在移动端 375px 下正常截断且不横向溢出。
2. **移动端下拉选择与桌面 Pills 互斥**：通过 CSS 媒体查询（`@media (max-width: 768px)`）严格控制展示与隐藏，确保桌面与移动端各司其职，无 DOM 重复绑定冲突。
3. **非安全上下文复制剪贴板**：针对内网 HTTP 访问无法调用 Clipboard API 的情况，内置经典 textarea 回退方案。
